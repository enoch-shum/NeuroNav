The Problem

The Mobility Gap

Over 11 million Americans suffer from Neurodegenerative diseases.

Currently, integrated smart wheelchair systems charge up to $350 - $750 per year for faint detection.

The Solution

What NeuroNav Does

We built a sub-$50 sensor suite with haptic feedback offering faint + obstacle detection.

Capabilities

Key Features

LiDAR Obstacle Detection

Time-of-Flight (ToF) sensors detect environmental hazards

Posture & Fatigue Tracking

An MPU-6050 IMU tracks Yaw, Pitch, and Roll to detect rapid head slumps

Multimodal Haptic Feedback

Vibration motors notify the user of nearby obstacles, communicating distance through vibration strength

Live Web Dashboard

A Next.js zero-latency interface allows caregivers & authorized HCPs to monitor the user's posture and surroundings remotely
